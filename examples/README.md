# Sample outputs

These examples use synthetic hackathon data and illustrate the structured,
role-aware output produced by Corporate Brain. They contain no customer,
employee, credential, or production information.

- [Ecommerce control plan](./ecommerce-control-plan.json): a Data Analyst checks
  dashboard readiness and proposes governed stockout and product-quality alerts.

The live application remains the source of truth. Example outputs are included
so judges can understand the response contract even if they review the written
submission without running the application.
