# Plantilla de teardown (una ficha por pieza)

Marcar cada dato: **[Obs]** observado · **[Inf]** inferido · **[Fuente]** externo sin verificar.

## 0. Identidad
- Enlace / archivo, plataforma, cuenta, fecha de captura, idioma.
- Proporción (9:16, 4:5, 1:1) y duración total.
- Señales públicas (vistas, likes, comentarios, días activo en la Biblioteca de Anuncios): **son indicios, no prueba de qué funciona.**

## 1. Gancho (0 a 3 s)
| Seg | Imagen | Audio / voz | Texto en pantalla |
|---|---|---|---|
| 0 a 1 | | | |
| 1 a 2 | | | |
| 2 a 3 | | | |
- Tipo: pregunta · promesa · shock · "POV" · "nadie te dice" · resultado primero · curiosidad abierta · otro.
- Primera imagen, primera frase, ¿habla a una persona concreta?

## 2. Estructura narrativa
Problema → mecanismo o demostración → prueba → oferta → CTA. Anotar el segundo en que aparece cada bloque y cuánto dura.

## 3. Gramática visual
Tipo de plano, cortes por segundo, subtítulos (estilo, posición, tipografía, color), música o voz, ritmo, zonas seguras respetadas (sí/no).

## 4. Formato
UGC a cámara · POV · pantalla grabada · pantalla dividida · antes/después · lista · storytime · carrusel · imagen estática · demostración.

## 5. Dispositivos de retención
Bucles abiertos, interrupciones de patrón (segundo exacto), promesas diferidas, cambios de plano/ritmo.

## 6. Embudo (lado web)
CTA exacto, destino, ¿la promesa coincide con el H1?, parámetros UTM, redirecciones, píxeles. Para esto sí puede servir REA.

## 7. Lectura
- Mecanismo que explica el patrón **[Inf]**.
- Qué se replica (estructura y formato) y qué NO (contenido, rostro, voz, música, marca).
- Riesgos de política.
